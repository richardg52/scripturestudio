# Table of 7

A family dining app: vote on where to eat, send formal invitations, settle one check together, check in at the table, and keep the photos and memories.

- **Try it:** open `index.html` in a browser. It has no build step.
- **Taking it live:** read [`HANDOFF.md`](HANDOFF.md). It covers the deploy steps, the shared backend plan, notifications, restaurant data and the checklist before the family uses it.
- **Host:** Richard Clark.
